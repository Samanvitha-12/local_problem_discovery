Civic complaint dataset for Smart Civic AI

This folder contains a curated local complaint dataset tailored to the civic issue categories used by the application:
- Road Damage
- Garbage
- Street Light
- Water Leakage
- Drainage
- Electricity
- Tree Fallen
- Flood
- Illegal Dumping
- Traffic Signal

Files:
- civic_complaints.csv: training-ready complaint dataset with columns: id, category, severity, priority_label, complaint_text, complaint_text_kn, location_hint, keywords
- civic_complaints.json: compact JSON summary of the dataset

This dataset is intended for local training and testing of complaint categorization and prioritization.
